First read each `repos/<repo>/AGENTS.md` (else `CLAUDE.md`): its project rules bind too and win any conflict, noted in your artifact.

1. **Simple.** Same destination, shortest path: keep every feature and correctness guarantee; if the logic goes 1→2→3→10 and 1→10 works, go 1→10 (intermediate states, extra events, error-code variants, patch fallbacks may go). Add no concept, state, field, error code or config the requirement did not ask for; if it forces one, say so. One fact, one place.
2. **Recoverable.** Resumable from any interruption: intent before action, atomic writes, idempotent replay. Before adding halfway-state logic, check whether restart recovery covers it. No I/O under a lock; no sleep posing as synchronization.
3. **Least privilege** (against accidents). Credentials stay out of agent env, command lines, logs and artifacts (name variables, never values). A new entry point states who can reach it.
4. **Evidence.** Verify before asserting; label guesses; back "absent" with how you searched. New-behaviour tests fail on the old code; never relax an assertion silently. Docs change with code. Confirm shipped features act on real data.
5. **The owner decides destinations.** Flag any removed feature, weakened guarantee or conflict with a past ruling and ask; a shorter path needs no ruling.
6. **Waiting.** Waiting is never a tool call of its own. Run a command in the foreground, never with a timeout or deadline of your own: the harness bounds each call by the step's tool window. If something must be awaited — a server coming up, a procedure already started — wait INSIDE the same call: a loop that checks a real condition, sleeps at most 3 s per iteration and has a deadline. A bare `sleep N` call, or a loop whose only exit is the deadline, is a violation and is recorded. The same binding covers a shell's `wait` and every background job: a `wait` is a wait like `sleep`, so never wait on something with no timeout of its own — await a real condition with a deadline, or bound and poll what you started. A step never manufactures artificial load on a shared host to reproduce a load-sensitive flake (spin loops, `yes`, stress tools): use the test's own parallelism knobs (`-parallel`, `E2E_JOBS`) or record the flake as load-sensitive in the conclusion. Every background process a step starts is bounded: kill it by process group before the call returns, with a `trap` as the backstop, and never pass a pid list through an unquoted shell variable. A background process does not survive this tool call: never start one in one call and wait for it in a later call. temporary files belong under `$TMPDIR` or `artifacts/downloads/`, never a fixed `/tmp/` name.
7. **Reuse before writing.** 先用仓里已有的函数、组件和既有写法，再用标准库或平台能力、已安装的依赖，最后才自己写；不为省几行代码新增依赖。
8. **Trusted boundaries.** 只在可信边界（用户或 CLI 输入、网络、文件、其他进程）做校验；进程内部不为调用方不可能产生的状态写防御分支或兜底；防丢数据的错误处理和安全相关代码不受此限。
9. **Scoped file reading.** 先用搜索定位，再按需要的行范围读；不整份读取大文件（以超过 16KB 为例），步骤指令明确要求读完整份的产物（例如 review 读 plan）除外。
10. **Shell separators.** 在 shell 里打印分隔线写成带引号的 `echo '----'`，不要写以 `=` 开头的未加引号的词。
